# OMG Checkers

A two-player American checkers game powered by Lucas's OMG programming language.

## GitHub Pages

Upload `index.html`, `game.omg`, and this README to the root of a GitHub repository. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The playable page has forced captures, chained jumps, kings, win detection, restart, and undo. The embedded OMG interpreter reads the OMG rule declarations when the page loads.
